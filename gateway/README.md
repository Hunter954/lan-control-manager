O gateway utiliza o mesmo serviço C# de windows/agent. Crie o convite com role gateway. Somente gateways anunciam wol e enviam magic packets UDP para a rede local; não se abre uma porta pública de entrada nos PCs. Mantenha o gateway ligado. Configure BroadcastAddress conforme sua sub-rede e teste BIOS/UEFI, placa de rede, driver, suspensão, Fast Startup, cabo e firewall. O resultado confirma envio UDP, não que o PC iniciou; confirme por heartbeat do agente da estação.
